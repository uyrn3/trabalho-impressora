# 🖨️ Integração C com Impressora Elgin i9

## 📘 Sobre o Projeto
Este projeto foi desenvolvido por alunos com o objetivo de criar uma aplicação em C capaz de se comunicar com a impressora **Elgin i9**, utilizando comandos ESC/POS, testes de impressão e interação via porta de comunicação. 

O trabalho faz parte da disciplina de **Programação Orientada a Objetos**.

---

## 🧰 Tecnologias Utilizadas
* **Linguagem:** C
* **Biblioteca:** Impressora E1 (Elgin)

---

## 📁 Estrutura do Projeto
```text
├── /src       → Código-fonte principal
├── /lib       → Bibliotecas e dependências externas
├── /docs      → Materiais adicionais e documentação
└── /examples  → Testes e arquivos de demonstração
```

---

## ⚙️ Instalação e Execução

### 🔽 1. Baixar o Projeto do GitHub
1. Acesse este repositório.
2. Clique no botão verde **Code**.
3. Selecione **Download ZIP**.
4. Aguarde a conclusão do download.

### 📦 2. Extrair o Arquivo ZIP
1. Vá até a pasta onde o arquivo foi salvo.
2. Clique com o botão direito sobre ele e selecione **Extrair aqui** (ou *Extract All*).
3. Uma nova pasta com os arquivos do projeto será criada.

### 🧭 3. Abrir com Dev-C++
1. Navegue até a pasta extraída.
2. Dê um duplo clique no arquivo do projeto (ou código-fonte) e abra-o com o **Dev-C++**.
3. Compile e execute o código.
